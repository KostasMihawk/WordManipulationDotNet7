# Διαχείριση Προτύπων Εγγράφων (Document Templates)

## 📄 Επισκόπηση

Η νέα λειτουργικότητα επιτρέπει την πλήρη διαχείριση των προτύπων εγγράφων (EkthesiEpidoshsModel) μέσω του Admin Panel.

## 🎯 Πρόσβαση

1. Πλοηγηθείτε στο Admin Panel: `/Admin`
2. Κάντε κλικ στην κάρτα **"Πρότυπα Εγγράφων"**
3. Ή πηγαίνετε απευθείας: `/Admin/Documents`

## ✨ Λειτουργίες

### 📋 Λίστα Προτύπων
- **URL:** `/Admin/Documents`
- **Προβολή:** Όλα τα πρότυπα ταξινομημένα κατά προτεραιότητα
- **Πληροφορίες:** ID, Προτεραιότητα, Όνομα, Τοποθεσία, Περιγραφή, και όλες οι ρυθμίσεις

### ➕ Προσθήκη Νέου Προτύπου
- **URL:** `/Admin/AddDocument`
- **Κουμπί:** "Προσθήκη Νέου Προτύπου Εγγράφου" στη σελίδα λίστας

### ✏️ Επεξεργασία Προτύπου
- **URL:** `/Admin/EditDocument/{id}`
- **Κουμπί:** Κίτρινο εικονίδιο μολυβιού (✏️) δίπλα σε κάθε πρότυπο

### 🗑️ Διαγραφή Προτύπου
- **Κουμπί:** Κόκκινο εικονίδιο κάδου (🗑️) δίπλα σε κάθε πρότυπο
- **Επιβεβαίωση:** Ζητάει επιβεβαίωση πριν τη διαγραφή

## 📝 Πεδία Προτύπου

### Βασικά Πεδία
- **Όνομα Προτύπου** (Name) - *Υποχρεωτικό*
  - Το όνομα του εγγράφου
  - Max 200 χαρακτήρες

- **Τοποθεσία** (Location) - *Υποχρεωτικό*
  - π.χ. "Εφοριες", "Cepal", "doValue", "Intrum", "QQuant", "Αλφα", "pqh"
  - Max 200 χαρακτήρες

- **Περιγραφή** (Perigrafh) - *Προαιρετικό*
  - Περιγραφή του προτύπου
  - Max 500 χαρακτήρες

### Ρυθμίσεις Προτεραιότητας
- **Αριθμός Προτεραιότητας** (PriorityNumber)
  - Χαμηλότερος αριθμός = Υψηλότερη προτεραιότητα
  - Default: 0

### Ρυθμίσεις Boolean
- **Πράξη** (Praxh) - *Προαιρετικό*
  - Ναι / Όχι / Κενό

- **Zone B** (ZoneB) - *Προαιρετικό*
  - Ναι / Όχι / Κενό

- **Φυσικό Πρόσωπο** (FusikoProswpo)
  - Ναι / Όχι
  - Default: Ναι

### Ρυθμίσεις Κλεισίματος
- **Τύπος Κλεισίματος** (HasKleisimo)
  - `exei` (έχει) - 0
  - `denExei` (δεν έχει) - 1
  - `MegaloKeno` (Μεγάλο Κενό) - 2

- **Κείμενο Κλεισίματος** (Kleisimo) - *Προαιρετικό*
  - Προσαρμοσμένο κείμενο κλεισίματος
  - Max 200 χαρακτήρες

### Τύπος Υπογραφής
- **Signature**
  - `paredros` (πάρεδρος) - 0
  - `ypallilos` (υπάλληλος) - 1
  - `paralavon` (παραλαβών) - 2
  - `genericMartyras` (γενικός μάρτυρας) - 3

## 🚀 Χρήση

### Παράδειγμα: Προσθήκη Νέου Προτύπου για "doValue"

1. Πηγαίνετε στο `/Admin/Documents`
2. Κλικ "Προσθήκη Νέου Προτύπου Εγγράφου"
3. Συμπληρώστε:
   - **Όνομα:** "doValue Επίδοση Β"
   - **Τοποθεσία:** "doValue"
   - **Περιγραφή:** "Πρότυπο για doValue B επιδόσεις"
   - **Προτεραιότητα:** 10
   - **Φυσικό Πρόσωπο:** Ναι
   - **Κλείσιμο:** exei
   - **Υπογραφή:** paralavon
4. Κλικ "Δημιουργία Προτύπου"

### Παράδειγμα: Ενημέρωση Προτεραιότητας

1. Πηγαίνετε στο `/Admin/Documents`
2. Βρείτε το πρότυπο που θέλετε
3. Κλικ στο κίτρινο εικονίδιο ✏️
4. Αλλάξτε τον **Αριθμό Προτεραιότητας**
5. Κλικ "Αποθήκευση Αλλαγών"

## ⚠️ Σημαντικές Σημειώσεις

1. **Διαγραφή:** Η διαγραφή προτύπου είναι μόνιμη - ΔΕΝ υπάρχει Undo
2. **Ονόματα:** Προτεινόμενη σύμβαση: `[Location] [Type] [Variant]`
3. **Location:** Πρέπει να ταιριάζει με τα folders στο ZIP export logic
4. **Priority:** Χρησιμοποιείται στη γεννήτρια εγγράφων για τη σειρά επεξεργασίας

## 🔍 Debugging

Αν τα πρότυπα δεν εμφανίζονται:
1. Ελέγξτε ότι το PostgreSQL τρέχει
2. Ελέγξτε τη σύνδεση στο `appsettings.json`
3. Τρέξτε migration: `dotnet ef database update`
4. Ελέγξτε τα logs στο `/Logs/log-{date}.txt`
